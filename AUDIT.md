# Аудит локального сайта

Проверены Python-маршруты, подсчёт баллов, выдача данных, DOM-рендеринг и состояния интерфейса.

Исправлено:
- Повторный запуск теста при быстрых нажатиях; добавлена блокировка запуска.
- Выход во время отправки результата; кнопка выхода блокируется до ответа сервера.
- Повторное продвижение вопроса; добавлена короткая блокировка перехода.
- Неограниченное ожидание сети и технические ошибки JSON; добавлен тайм-аут 15 секунд и понятные сообщения.
- Отсутствие проверки данных при загрузке; проверяются непустой тест, уникальные ID, варианты и ключи.
- Неограниченный размер HTTP-тела; установлен предел 64 КиБ с JSON-ответом 413.
- Добавлены CSP, запрет встраивания, nosniff, no-referrer и no-store для API.

Проверка: 6 unittest-тестов проходят; проверены правильные ответы, пропуски, неверные типы, неизвестные ID, повреждённый JSON, превышение лимита, закрытые файлы, заголовки и некорректные наборы вопросов. В браузере проверены загрузка, выбор ответа и переход с CSP.

Ограничения:
- Это тренажёр: сервер возвращает ключ после POST, даже при пустых ответах. Нет контроля завершения попытки. Для экзамена нужны серверные попытки и правила выдачи разбора.
- Таймер убран: тренажёр позволяет пробовать варианты до верного ответа. Итог учитывает первые ответы.
- Результаты не хранятся; обновление страницы теряет попытку, браузер предупреждает перед уходом.
- Вопрос 12 содержит два одинаковых варианта; ответ 51 добавлен по смыслу, не взят из исходного ключа.
- Проверка не является полноценным пентестом. Отдельное сканирование зависимостей по базе CVE не выполнялось.

Запуск проверок: `.venv/Scripts/python.exe -m unittest discover -s tests -v`.
