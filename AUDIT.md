# Аудит локального тренажёра — 10.10.2026

Проверены загрузка данных, API, постраничная выдача, подсчёт первых ответов, рендеринг через textContent, обработка ошибок и выход из тренировки.

Исправлено:
- Отправка результата отклоняет варианты, которых нет в конкретном вопросе.
- Повреждённые типы в исходном JSON дают понятную ошибку проверки данных.
- Повторное нажатие загрузки не запускает параллельный рендер вопроса.
- Автоматический переход ожидает закрытия окна выхода, не закрывает его сам.
- Предупреждение об уходе сохраняется после неудачной отправки результата.
- Название группы ответов доступно скринридеру после перерисовки.
- Конвертер проверяет SHA-256 исходного документа: фиксированные границы разделов нельзя применять к другому DOCX.

Проверка: 13 unittest-тестов проходят; страницы всех 13 предметов и результаты проверены. JavaScript проходит node --check. Повторная конвертация полностью совпадает с 13 JSON-файлами: 4680 вопросов. В браузере проверены неправильный ответ, повторный выбор и окно выхода после правильного ответа.

Ограничения исходных данных:
- 847 повторов текста вопросов сохранены из документа.
- У двух вопросов неполный набор вариантов.
- Раздел национальных игр содержит 180 вопросов вместо заявленных 400.
- Правильный ответ A перенесён по соглашению исходного документа; содержательная правильность 4680 ответов независимо не проверена.

Ограничения приложения:
- Это тренажёр: результат и ключи можно получить через API; нет серверной защиты экзаменационной попытки.
- Результаты не сохраняются между обновлениями страницы.
- Docker/Railway и полноценная нагрузка на развёрнутом сервисе в этом аудите не проверены.
- Проверка кода не заменяет полноценный пентест или сканирование зависимостей по базе CVE.
